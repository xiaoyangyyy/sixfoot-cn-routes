# Six Foot city tracks (GPX)

Public trips from [六只脚](https://www.foooooot.com/) for Chinese cities. This release includes the **13 cities that have finished downloading**: **118,549 tracks**.

The GPX files are not stored in this repository. Each city is one zip on [Release v1](https://github.com/xiaoyangyyy/sixfoot-cn-routes/releases/tag/v1).

A zip unpacks to one city folder. Inside it, trips are grouped by activity, and there is a `路线清单.csv` index.

Each GPX is one recorded trip. Every point has:

- `lat`, `lon`: latitude and longitude
- `ele`: elevation in meters
- `time`: UTC timestamp

There is no heart rate, speed, or user id in the file. The activity is the folder name.

## 中文

这些是六只脚上的公开行程，本 Release 先放已经下完的 13 个城市，共 118,549 条。

轨迹在 [Release v1](https://github.com/xiaoyangyyy/sixfoot-cn-routes/releases/tag/v1) 的城市压缩包里。解压后按活动分子文件夹，并有一份 `路线清单.csv`。

每个点有纬度、经度、海拔（米）和 UTC 时间。没有心率、速度和用户信息。活动类型看文件夹名。城市与条数见上方英文表格。
