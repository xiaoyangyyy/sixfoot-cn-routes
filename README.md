# 六只脚城市轨迹（GPX）

这些是 [六只脚](https://www.foooooot.com/) 上的公开行程。这一版先放已经下完的 **21 个城市**，共 **170,875 条**。

轨迹文件不在仓库正文里。每个城市一个压缩包，在 [Release v1](https://github.com/xiaoyangyyy/sixfoot-cn-routes/releases/tag/v1)。

解压后是城市文件夹。里面按活动类型分子文件夹，并有一份 `路线清单.csv`。

每条 GPX 是一条带时间的行程。每个点有：

- `lat`、`lon`：纬度、经度
- `ele`：海拔（米）
- `time`：UTC 时间

文件里没有心率、速度和用户信息。活动类型看文件夹名。

常见活动目录：徒步、登山、跑步、骑行、公路骑行、山地骑行、越野、滑雪、自驾、摩托、摄影、观光、水上、滑翔、寻宝、GPS绘画、其他。
